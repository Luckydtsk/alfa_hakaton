# Кабинет финансирования

Прототип кредитного конвейера для малого и микробизнеса. Клиент описывает задачу, кабинет предлагает продукт, проводит смоделированные проверки и показывает решение. Сотрудник банка разбирает серую зону.

Оценка риска — уже обученная модель в `scoring/`. Она возвращает вероятность списания. Одобрение, отказ, другие условия и запрос данных считает бэкенд отдельно.

## Запуск для жюри

Нужны Docker Engine и плагин Compose.

```bash
cp .env.example .env
docker compose up --build
```

Кабинет: http://localhost:8080

Пароль у всех тестовых пользователей: `demo`

| Логин | Что увидите |
|---|---|
| client.good | Одобренная заявка. Можно подготовить документы и смоделировать выдачу |
| client.cafe | Отказ, на экране вероятность списания |
| client.thin | Не хватает данных. После дополнения заявка идёт дальше |
| client.border | Другие условия. Их можно принять или отклонить |
| client.closed | Отказ, потому что компания ликвидирована. Модель не вызывается |
| client.gray | Заявка в серой зоне |
| bank.underwriter | Очередь сотрудника. Серую заявку можно одобрить |

Сценарий по шагам: `docs/demo-scenario.md`. Сервер: `docs/deploy.md`.

## Архитектура

Браузер говорит только с контейнером `web`. Он отдаёт страницу и проксирует `/api` в `api`. API пишет состояние в Postgres и вызывает `scoring` внутри сети Compose. Скоринг и база наружу не публикуются.

Схема: `docs/architecture.md`. Состояния заявки: `docs/application-states.md`. Данные: `docs/data-model.md`. Контракт: `docs/openapi.yaml`.

## Переменные

Смотрите `.env.example`.

- `POSTGRES_PASSWORD` — пароль базы
- `SESSION_SECRET` — секрет сессии
- `FX_RUB_PER_USD` — курс, которым рублёвая сумма переводится в доллары перед моделью. По умолчанию 90. Модель обучена на долларах SBA, в кабинете суммы остаются в рублях
- `PD_APPROVE` — ниже этого порога и внутри лимитов продукта заявка одобряется сама. По умолчанию 0.03
- `PD_REVIEW` — начиная с этого порога заявка получает отказ. Между порогами её смотрит сотрудник. По умолчанию 0.12

Лимиты: оборотный кредит до 5 млн ₽ и 12 месяцев, залог не обязателен. Кредит на оборудование до 20 млн ₽ и 36 месяцев, залог обязателен.

## Модель

`POST /score` внутри сети скоринга. Поля и ответ описаны в `scoring/features.json`. Обёртка `scoring/server.py` только вызывает готовую функцию `score()`. Веса и признаки не меняются.

Отрасль в форме русская. Бэкенд подставляет код NAICS: кафе 72, розница 44, опт 42, строительство 23, производство 31, транспорт 48, услуги и IT 54, медицина 62, образование 61, сельское хозяйство 11, прочие услуги 81.

В обучающей выборке кредиты на 12 месяцев списывались заметно чаще, чем на 36. Новая оборотная заявка на 12 месяцев поэтому часто получает отказ. Демо-одобрение специально стоит на 36 месяцах и кредите на оборудование.
